Our Philosophy

// About

Built for those who take system integrity seriously.

SETFOP is a Linux utility crafted with a singular purpose — to give you precise control over ownership and permissions without compromise. Designed for administrators, DevOps engineers, and power users who believe a stable system is not a luxury, but a baseline requirement.

At its core, SETFOP is built on three uncompromising principles: preventing configuration drift before it begins protecting critical paths from unsafe or unintended changes, and preserving the integrity of your environment through every operation.

►

Prevent

Stop permission drift before it spreads. SETFOP captures and controls ownership and access states at the source — before inconsistencies take hold.

►

Protect

Shield critical paths with deliberate enforcement. Every change is validated, applied with intent and guarded against unsafe modification.

►

Preserve

Sustain stability through consistency. Because a controlled system is not just secure — it is reliable, reproducible, and built to last.

SETFOP CLI

Command Help

Use the SETFOP command-line interface to create templates, apply filesystem metadata, validate destinations, inspect templates and logs, and view SETFOP information.

●

Quick Start

$ setfop help
Available Commands
+
setfop create

Create a SETFOP template from a source directory. The template captures filesystem metadata. 

setfop create <template_name> <source_path>

Example:
setfop create my-template /etc/myapp
►
setfop apply

Apply a template to a destination target. Use --dry-run when you want to preview the operation. 

setfop apply <template_name> <destination_path> [--dry-run]

Example:
setfop apply my-template /tmp/testroot

Dry-run:
setfop apply my-template /tmp/testroot --dry-run
✓
setfop validate

Verify a destination filesystem against an existing SETFOP template specification. 

setfop validate <template_name> <destination_path>

Example:
setfop validate my-template /tmp/testroot
■
setfop list-templates

List the SETFOP templates currently available. 

setfop list-templates

Example:
setfop list-templates
≡
setfop list-logs

List the operation logs generated by SETFOP. 

setfop list-logs

Example:
setfop list-logs
i
setfop info

Display the SETFOP banner and CLI information. 

setfop info

Example:
setfop info
?
setfop help

Display the SETFOP command usage and help information. 

setfop help

Example:
setfop help
#
setfop version

Display the installed SETFOP version. 

setfop version

Example:
setfop version
Typical Workflow
01

Create a template

Capture filesystem metadata from your source directory into a SETFOP template.

02

Preview or apply

Use apply to deploy the template, or use --dry-run first to preview what SETFOP will do.

03

Validate

Run validate against the destination to verify the filesystem against the specification.

SETFOP Notes

Good to Know

  • Templates: /var/lib/setfop/templates/<name>.setfop
  • Logs: /var/log/setfop/
  • Log types include: create, apply, dry-run, validate and copy.
  • SETFOP captures metadata only: mode, owner, group and symlink target.
  • SETFOP does NOT copy file contents.
